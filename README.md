# Systemic Recruitment Disparity Simulator

## Overview

The **Systemic Recruitment Disparity Simulator** is an interactive project designed to model how multiple stages of a recruitment process can influence candidate progression.

The project explores how barriers introduced at different points in a hiring pipeline can compound over time and affect who advances through the process.

Rather than examining a single hiring decision in isolation, the simulator provides a way to visualize recruitment as a sequence of stages.

## 🎯 Project Purpose

This project was created to explore questions such as:

- How can multiple screening stages affect candidate progression?
- What happens when barriers accumulate across a recruitment pipeline?
- How can data and simulation be used to examine potential disparities?
- How might algorithmic screening and human decision points interact within a hiring process?

## 📊 Project Approach

The simulator represents recruitment as a series of decision points. Candidates move through successive stages, allowing users to explore how changes in individual stages can influence overall progression.

The project is intended as an **exploratory simulation**, not as a statistical estimate of real-world hiring outcomes.

## ⚠️ Important Limitation

This simulator is a conceptual modeling tool.

Its results depend on the assumptions and parameters built into the model and should not be interpreted as measurements of actual recruitment outcomes for any specific population, organization, or employer.

The purpose is to encourage exploration of how cumulative decision points can affect outcomes and to demonstrate how simulation can be used to examine complex systems.
